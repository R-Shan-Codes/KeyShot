# KeyShot

Windows desktop application that turns keyboard key presses into configurable weapon sound effects.

## Project Status

Phase 0 — Foundation

## Planned Architecture

- Windows desktop UI
- Global keyboard input listener
- Low-latency audio engine
- Weapon and sound-pack abstraction
- Non-repeating sound variation selector
- Persistent configuration

## Development

Target platform: Windows

Primary stack: C# / .NET / WPF
